## 🚀 Hero Projects

### 🤖 Metalytics
**AI-powered Aluminium Price Intelligence**

A real-time LME + NALCO pricing dashboard with AI-generated procurement signals — built for India's aluminium supply chain.

- 📊 Live LME & NALCO price feeds with Recharts visualizations
- 🧠 Claude-powered "Golden Prompt" for structured price forecasts
- 📅 Weekly outlook table with expandable rows & AnimatePresence
- 🌐 Geopolitical & supply risk signals across 6 dashboard tabs
- ⚡ React + TypeScript + Tailwind · Deployed on Vercel
